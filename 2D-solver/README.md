# PHASES

Solver for enclosed and open spaces.

## Compilation

```bash
# make
```

## Usage

```bash
# ./run <path_to_scene.obj> <path_to_config.txt> <path_to_sources.txt> <path_to_receivers.txt>
```

## Plotting

```bash
# python3 scripts/plot.py
```

Video animation will be in the output directory.
